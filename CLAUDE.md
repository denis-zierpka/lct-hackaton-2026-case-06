# CLAUDE.md — Питомец Финни

Игровое Android-приложение по финансовой грамотности для детей 7–11 лет.
Кейс 06 ЛЦТ-2026, заказчик — Департамент финансов города Москвы.
Kotlin + Jetpack Compose (Material 3), один Gradle-модуль, без сервера.
Общение — по-русски.

Файл грузится в главную сессию и в каждый подагент, поэтому держим его коротким:
только инварианты. Обоснования решений — в спеках `docs/tasks/`, история — в коммитах.

**Новая сессия начинает с `docs/HANDOFF.md`** — где остановились, следующий эпик, окружение.
Раз в 1–2 эпика сессия обновляет его и передаёт работу новой (решение 2026-09-25).

## Раскладка репозитория

```
docs/                 процесс контура, ТЗ и рамка компетенций (sources/), карта компетенций
finny-pet/            само приложение — Gradle-проект, все команды сборки отсюда
  app/src/main/…/domain/   правила игры, чистый Kotlin
  app/src/main/…/data/     чтение контента, сохранение профиля
  app/src/classic/         вариант сборки «classic» (обычный интерфейс)
  app/src/game/            вариант сборки «game» (комната, звуки, мини-игра)
  app/src/main/assets/content/content.json   учебный контент и числа экономики
  app/src/test/            JVM-тесты — ОРАКУЛ
  docs/                    документация для сдачи (раздел 5 ТЗ) + QUESTIONS, USER_TESTING
```

## Роли

| Роль | Кто | Права |
| --- | --- | --- |
| Оркестратор | главная сессия | всё; пишет спеки и приёмку, коммитит |
| Автор тестов | подагент `test-author` | пишет только в `finny-pet/app/src/test/` |
| Кодер | подагент `coder` | пишет только в whitelist задачи |
| Ревьювер | подагент `reviewer` | read-only, выносит вердикт |

## Источник правды

`docs/sources/ТЗ_текст.txt` — требования заказчика, ссылаться номером раздела и цитатой.
`docs/competencies.md` — чем обосновываем механики (рамка — каталог формулировок,
её деление на уровни не используем). `finny-pet/docs/ECONOMY.md` — формулы.
`finny-pet/docs/REQUIREMENTS_MATRIX.md` — статус по требованиям.
`docs/WORKFLOW.md` — процесс, шаблоны и уроки. Меняешь правило — обнови доку.

## Инварианты проекта (нарушать нельзя ни по какой просьбе таска)

- **`domain/` — чистый Kotlin.** Запрещены импорты `android.*`/`androidx.*`,
  системное время, случайность не от переданного seed (`Match3` берёт `Random(seed)`).
  Игровой период — счётчик, а не календарь: демо-режим обязан проходить 5 периодов
  подряд без ожидания (ТЗ 2.5.13, 2.6).
- **Числа экономики — только в `content.json` (`rules`)**, в коде не хардкодить.
  Спорное число не выдумывать: заглушка + `TODO` + вопрос сеньору.
- **Контент данными.** Новое задание, товар, цель — запись в `content.json`,
  без правки логики (ТЗ 2.5.14). Нужна новая механика — показать в спеке, чего
  не хватает в существующих полях.
- **Ноль разрешений, сети, рекламы, персональных данных** (ТЗ 3.1.4, 3.5).
  Любое новое `uses-permission` — только с обоснованием в спеке и в
  `finny-pet/docs/PRIVACY_PERMISSIONS.md`.
- **Тексты для ребёнка не стыдят и не пугают** (ТЗ 3.5): питомец грустит, но не
  болеет и не умирает от ошибок. Ошибка = понятная задача на восстановление (2.2).
- **Доступность — требование, а не украшение** (ТЗ 3.6): кнопки от 48 dp, текст
  от 16 sp с системным масштабом, цвет не единственный признак, звук и анимация
  отключаемы.
- **Сдаём вариант `game`** (решение сеньора 2026-09-23). `classic` остаётся в
  репозитории, но UI-задачи по умолчанию — для `game`. Общее — в `main/`.
  Следствия выбора и открытые вопросы — `docs/BACKLOG.md`.
- **Питомец:** до промежуточной сдачи — процедурный рендер `tools/art/pet.py`
  (кот, зайка, щенок — щенок вместо дракона, решение 2026-09-25); 3D-модели с ручной
  анимацией — к финалу, план — `docs/ART_PIPELINE.md`.
- **Доки не врут о коде.** Любое изменение поведения сопровождается грепом по
  формулировке старого правила по ВСЕМУ репозиторию (оба `docs/`).
- **Ассеты — с лицензией в момент добавления** (`finny-pet/docs/LICENSES.md`),
  генераторы — в `finny-pet/tools/art/`, из них пересобираются.

## Инварианты контура

1. **Тесты пишет не тот, кто пишет код.** Оракул готовит `test-author` до старта
   кодера; кодеру `app/src/test/` закрыт хуком `guard-paths.js`.
2. **Приёмка машинная**, гоняет её оркестратор — блок из `docs/ACCEPTANCE_PRESETS.md`.
   Самоотчёт агента «готово» приёмкой НЕ является.
3. **Ревьювер не видит контекста кодера и не чинит код** — выносит `PASS`/`FAIL`
   со списком нарушенных пунктов.
4. **Whitelist файлов** в `.claude/task-scope.json` пишется перед спавном кодера.
   Всё, чего там нет, кодеру писать нельзя.
5. **Блокер — не повод изобретать.** Противоречивая спека или неполный контракт →
   `STATUS: BLOCKED` с ОДНИМ конкретным вопросом и остановка.
6. **Ноль новых зависимостей** без явного разрешения в спеке.

Отчёт любого агента: `STATUS: DONE | BLOCKED | FAILED` / `FILES` /
`CHECKS: <команда> -> <фактический exit code | не запускал>` / `NOTES` (≤5 строк).

Запрещённые формулировки в отчётах и ревью: «в целом хорошо», «незначительные
замечания», «работает как ожидается», «должно работать», «я исправил все проблемы».
Только проверяемые утверждения с командой и её выводом.

## Окружение

- **Сборка — из `finny-pet/`, JDK 17, Android SDK (platform 36, build-tools 36.0.0).**
  Путь к SDK — в `finny-pet/local.properties` (в `.gitignore`).
  - Windows (основная машина с 2026-09-25): `JAVA_HOME` — установленный JDK 17
    (Adoptium), SDK — `%LOCALAPPDATA%\Android\Sdk`, в `local.properties` двоеточие
    экранируется: `sdk.dir=C\:/Users/…/Android/Sdk` (иначе lint даёт ошибку
    PropertyEscape). Gradle — `gradlew.bat`, Python — `python` (`python3` — заглушка Store).
  - Linux: `JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64`, `ANDROID_HOME=~/android-sdk`,
    `./gradlew`, `python3`.
- **Хуки на Node**, пути к ним — через `$CLAUDE_PROJECT_DIR`, корень хуки находят сами
  (подагент может сделать `cd finny-pet`). Проверка guard: `node .claude/hooks/guard-paths.test.js`
  из корня репозитория, включая Windows-кейсы (обратные слэши, регистр, PowerShell).
- **Эмулятор.** Windows: AVD `finni` (Android 16, x86_64, WHPX, 3 ГБ ОЗУ), запуск
  `%LOCALAPPDATA%\Android\Sdk\emulator\emulator -avd finni`, проверка 360 dp —
  `adb shell wm size 1080x1920 && adb shell wm density 480`, сброс — `wm size reset`,
  `wm density reset`. Linux — `tools/emu.sh`. Одновременно со сборкой Gradle можно.
  Сессия сама снимает скриншоты «до/после». Физическое устройство (ТЗ 3.1.3),
  плавность и звук проверяет человек.
- **Живая проверка экранов** — `tools/adbui.sh` (эмулятор или телефон S23, `ANDROID_SERIAL`);
  на телефоне тесты без звука (`mute` / `unmute`). Снимки `finny-pet/screenshots/emu_*` в git не идут.
- **Спавн подагента:** инструмент Agent/Workflow сессии с `agentType` из `.claude/agents/`
  (`test-author`, `coder`, `reviewer`) — тогда хук видит `agent_type`. Обрыв или пустой
  `BLOCKED` ≠ «работы нет»: смотреть файлы, а не отчёт.

## Коммиты

Коммиты — по задачам (`<ID>: …`, `test(<ID>): …` для оракула). Репозиторий
общий с командой. Пуш на GitHub — только по явной просьбе сеньора (на прогон
MVP 7.1 дано разрешение пушить ветку `feat/mvp-7-1` и влить её в `main` в конце).
