## 1.3.0 — 2026-09-25

Промежуточная сдача (ТЗ 7.1). Сдаётся вариант **game**.

### Изменено

- **Сдаётся game**: пакет `ru.finny.pet`, название «Питомец Финни», versionCode 4, versionName 1.3.0 (ТЗ 3.3). Вариант classic остаётся в репозитории как `ru.finny.pet.classic`, «Финни classic», 1.3.0-classic, в сдачу не входит — [app/build.gradle.kts](app/build.gradle.kts). Версия на экране взрослого берётся из `BuildConfig`.
- **Щенок вместо дракона**: виды кот, зайка, щенок × 3 цвета × 3 стадии (ТЗ 2.6); 108 спрайтов перерендерены (`tools/art/pet.py`, `tools/art/import_sprites.py`), в `content.json` вид `puppy`.
- **Награда за задание**: верно 20 → **10**, неверно 5 (ТЗ 2.1: за неделю нельзя купить всё) — `rules.rewardCorrect` в [content.json](app/src/main/assets/content/content.json).
- **Барьер для взрослого сложнее**: двузначное × однозначное (12…19 × 3…9), после ошибки — новый пример (ТЗ 2.5.12) — [ParentScreen.kt](app/src/game/java/ru/finny/pet/game/screens/ParentScreen.kt).
- **Тексты**: «монет» склоняется по числу и падежу во всех сообщениях правил (`Economy.coins(n, Case)`) — [Economy.kt](app/src/main/java/ru/finny/pet/domain/Economy.kt); обращение к ребёнку без рода в правилах, заданиях, справочнике и причинах бонуса (ТЗ 8.3, 3.5). Строки экранов game пока пишут «монет» после любого числа (например, «Давай разделим 101 монет» — [GameViewModel.kt](app/src/game/java/ru/finny/pet/game/GameViewModel.kt), а также PlanScreen, ShopScreen, SavingsScreen, ParentScreen, RoomScreen, ProgressScreens) — к финалу. Спека: [MVP-T01a](../docs/tasks/MVP-T01a.md).
- **Вёрстка портрета 360 dp**: главный экран — колонка без наложений; план, магазин, копилка без обрезанных слов (переносы по слогам, товары и цели в 2 колонки); в разделе для взрослого убрано «базовый уровень». Спека: [MVP-T09](../docs/tasks/MVP-T09.md).
- Пороги настроения, стартовые показатели, шаг плана, суммы копилки — в `rules` из `content.json`, а не в коде (domain и game). В classic шаг плана и суммы копилки по-прежнему в коде: `STEP` в [classic PlanScreen.kt](app/src/classic/java/ru/finny/pet/ui/screens/PlanScreen.kt), `amounts` в [classic SavingsScreen.kt](app/src/classic/java/ru/finny/pet/ui/screens/SavingsScreen.kt).
- Release game для 7.1 подписан debug-ключом (`keystore.properties` нет), постоянный ключ — к финалу. Файл сдачи: `release/finny-pet-1.3.0-release.apk`.

### Добавлено

- **Бонус взрослого**: +10 до 3 раз в неделю, причина из списка (4 причины в `parentBonusReasons`), с подтверждением и записью в журнал (ТЗ 2.5.12).
- **«Вне плана» в итоге недели**: отдельные строки для монет из мини-игры и бонуса взрослого (ТЗ 2.8).
- **Мини-игра «Монетки в ряд» только после плана**: до подтверждённого плана вместо поля — объяснение (`Economy.miniGameLock`); 1 монета за 20 очков, не больше 30 за неделю (ТЗ 2.7, 2.8).
- **«Назад» в мини-игре** = «Закончить»: итог партии, затем начисление — [MiniGameScreen.kt](app/src/game/java/ru/finny/pet/game/screens/MiniGameScreen.kt).
- **Звуки и музыка раздельно**: два переключателя, музыка по умолчанию выключена; настройки переживают сброс профиля.
- **Плашка «Сейчас»** на главном экране — текущий шаг недели (ТЗ 2.5.3) — [RoomScreen.kt](app/src/game/java/ru/finny/pet/game/screens/RoomScreen.kt).
- **Причина настроения по нажатию** на питомца (ТЗ 2.5.10).
- **Доступность (ТЗ 3.6)** — спека [MVP-T04](../docs/tasks/MVP-T04.md):
  - касания ≥ 48 dp (цвета, «−/+» плана, имена, цены, «Выбрать»);
  - основной текст 16 sp, мелкий — 14 sp; панели комнаты растут со шрифтом, сцена комнаты и мини-игра ограничивают масштаб шрифта 1,3;
  - выбор не только цветом: «✓» и роль радиокнопки для TalkBack у кнопок и карточек вида/цвета;
  - переключатель «Анимации» и системное отключение анимаций убирают их целиком: частицы, переходы, пружины, анимации шкал и мини-игры.
- **Документы**: [docs/QUESTIONS.md](docs/QUESTIONS.md) — вопросы заказчику (ТЗ 7.1 п. 7); [docs/USER_TESTING.md](docs/USER_TESTING.md) — протокол проверки с пользователями (ТЗ 8.4), проверка не проводилась; экономика, модель данных, контент и архитектура переписаны под 1.3.0.

### Исправлено

- Снятие из копилки больше не проваливает «траты по плану»: чистое снятие считается как 0 отложено.
- Повторный ответ на уже решённый вопрос питомца — ошибка, а не вторая награда.
- Звуки еды и ухода играют; `SoundPool` освобождается при выходе.
- Тексты конца недели без упрёка.

### Удалено

- Материалы classic из дерева: DOCX, PPTX, demo.mp4, 65 скриншотов, release APK 1.2.0 (остаются в истории, коммит `83404be`). Материалы game к финалу пересобираются.
