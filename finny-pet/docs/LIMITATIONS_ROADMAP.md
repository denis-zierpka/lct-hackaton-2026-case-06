# Известные ограничения прототипа и план развития

## Ограничения

| Ограничение | Причина | Влияние |
|---|---|---|
| Проверка выполнена только на эмуляторе (arm64, Android 16) | В сессии разработки не было физического устройства | Перед сдачей команде нужно прогнать TC-01…TC-12 на реальном телефоне (см. TEST_CASES.md) |
| Игровая неделя завершается кнопкой, привязки к реальному календарю нет | Осознанное решение: демо-режим и обычный режим используют один цикл; ТЗ разрешает | Ребёнок может «прокрутить» недели быстро; ограничитель — родитель и естественный интерес |
| Родитель не может начислять дополнительные баллы | Необязательное требование 2.5.12, отложено | Нет семейного взаимодействия через приложение |
| Питомец рисуется примитивами (Canvas), без профессиональной графики | Отсутствие лицензионных ассетов; собственная отрисовка без вопросов авторского права | Внешний вид простой, но 9 комбинаций различимы |
| Нет звуков | Ничего не нужно отключать; важная информация текстом | Меньше «игровой» атмосферы |
| Один локальный профиль на устройство | Упрощение для прототипа | Двое детей на одном телефоне делят профиль |
| Нет iOS-версии; на планшете одна колонка контента (рейл навигации есть, двухпанельных раскладок нет) | Не входит в конкурсный минимум | — |
| Экспрессивные компоненты M3 (волнистые индикаторы, `MotionScheme`) не используются | В Material3 1.4.0 они internal; стабильны только в 1.5 | Движение построено на стандартных переходах и spring-анимации питомца |
| Публикация в RuStore не выполнена | Не входит в минимум (2.7.4); подготовлена карточка и подписанная сборка | — |

## План развития

1. **Проверка с детьми.** Пилот с 5–8 детьми 7–11 лет при согласии законных представителей; замер понимания трёх решений и удовольствия от питомца; корректировка текстов.
2. **Календарная привязка (опционально).** Ежедневный вход даёт небольшой доход, неделя завершается автоматически в выходной; демо-режим остаётся без ожидания.
3. **Родительские бонусы.** Родитель начисляет монеты за реальные дела (уборка, чтение) из своего раздела; правило и лимит — в контенте.
4. **Больше контента.** По 3–5 заданий на тему, сезонные товары, случайные события («непредвиденные расходы» с выбором), второй набор целей. Всё — через `content.json`, без изменения кода.
5. **Графика и звук.** Художественные спрайты для 3 видов × 3 стадий, короткие реакции; переключатели уже есть.
6. **Несколько профилей** на устройстве и экспорт прогресса в файл для родителя.
7. **Публикация.** Карточка RuStore, тестирование на устройствах 360 dp / Android 8–16, возрастная маркировка, политика конфиденциальности.
8. **Планшет** — двухпанельная раскладка главного экрана (питомец слева, план/задания справа) поверх уже работающего рейла навигации; переход на Material3 1.5 ради экспрессивных индикаторов и `MotionScheme`.
