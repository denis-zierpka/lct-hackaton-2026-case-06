# Разрешения Android, данные и удаление профиля

## Разрешения

Приложение не запрашивает ни одного разрешения Android. В `AndroidManifest.xml` нет элементов `<uses-permission>`: не нужны интернет, камера, микрофон, геолокация, контакты, Bluetooth, хранилище. Основной игровой цикл работает полностью офлайн.

## Собираемые данные

Не собираются. Приложение не содержит аналитики, рекламы, SDK третьих сторон, сетевых вызовов и не создаёт аккаунтов.

Единственные данные — локальный игровой профиль в приватной папке приложения `filesDir/state.json` (недоступна другим приложениям):

- игровое имя питомца (вводится ребёнком, не является персональными данными по замыслу — ребёнок называет персонажа);
- вид и цвет питомца, показатели, стадия;
- игровая валюта, копилка, план, покупки, цель, результаты заданий, итоги недель;
- настройки: демо-режим, анимации.

Резервное копирование Android отключено (`android:allowBackup="false"`), поэтому файл не уходит в облако.

## Удаление и сброс

Из раздела для взрослого (барьер — арифметический пример), без обращения к разработчику:

- «Сбросить профиль» — прогресс обнуляется, настройка демо-режима сохраняется;
- «Удалить профиль и данные» — файл состояния перезаписывается пустым профилем;
- «Создать тестовый профиль (демо)» — сброс с включённым демо-режимом для экспертной проверки.

Каждое действие требует подтверждения. Полное удаление приложения также удаляет папку `filesDir`.

## При дальнейшей публикации

При добавлении облачных функций потребуется политика конфиденциальности, согласие законного представителя и соблюдение 152-ФЗ, 436-ФЗ и правил RuStore. Текущий прототип этих функций не содержит, поэтому возрастная маркировка — 0+.
