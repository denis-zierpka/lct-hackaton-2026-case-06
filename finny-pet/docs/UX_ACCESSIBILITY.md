# UX/UI-решения и доступность

Интерфейс построен на Material Design 3 (Jetpack Compose Material3 1.4): токены цвета, типографики и формы, стандартные компоненты, адаптивная навигация, тёмная тема. Цель — чтобы ребёнок 7–11 лет узнавал знакомые элементы Android, а взрослый видел аккуратное современное приложение.

## Дизайн-система

| Слой | Решение | Где |
|---|---|---|
| Цвет | Палитра шаблона презентации ЛЦТ-2026: primary — фирменный фиолетовый `#520978` (в тёмной теме тон 80), secondary — акцентная фуксия `#FF0053` (для текста и иконок тон 45 `#D50044`, контраст ≥ 4.5:1; контейнер `#FFD6E4` из шаблона) — копилка, цель, «Сейчас», индикатор навигации; tertiary — лаванда `#8A83D1` — задания и уход. Тональные палитры по алгоритму Material (material-color-utilities), нейтральные поверхности заданы вручную: белые карточки на светло-сером `#F4F2F8`, тёмная тема на `#16151B` (базовый `#1C1D22` шаблона). Фиксированные цвета: золото монеты, зелёный `success` для галочек и роста (в палитре шаблона зелёного нет, а галочка должна читаться как галочка). Все роли M3 для светлой и тёмной темы | `tools/office/gen_theme.js` → `ui/Colors.kt`, `ui/Theme.kt` |
| Фирменный hero | Градиент `#310F53 → #520978 → #8E1F8F` (обложка ТЗ и титульные слайды шаблона) на одной поверхности экрана: питомец на главном, обложка знакомства, превью при создании; на нём белый текст и пастельные полосы показателей | `BrandHero` в `ui/Components.kt` |
| Типографика | Montserrat (шрифт шаблона ЛЦТ, SIL OFL, один variable-файл 730 КБ) по шкале M3, увеличенной под возраст: основной текст 17 sp, вспомогательный 16 sp, подписи 14 sp; заголовки Bold/ExtraBold | `ui/Theme.kt`, `res/font/montserrat.ttf` |
| Форма | Скруглённые токены (карточки 24 dp, поля 16 dp, кнопки «pill») — экспрессивный вариант M3, дружелюбный для детей | `ui/Theme.kt` |
| Отступы | Сетка 8 dp: `Space.xs/sm/md/lg/xl` = 4/8/16/24/32 dp; поля экрана 16 dp, ширина контента ≤ 640 dp на широких окнах | `ui/Theme.kt`, `ScreenScaffold` |
| Возвышение | Тональные поверхности вместо теней: карточки белые (`surfaceContainerLowest`; в тёмной теме `surfaceContainerLow`, чтобы карточка была светлее фона), акцентные — на `primaryContainer/secondaryContainer/tertiaryContainer` | `SectionCard`, `FinnyColors.card` |
| Движение | Переходы между экранами — `AnimatedContent` с emphasized-кривыми M3 (350/150 мс); полосы показателей анимируются; питомец дышит, моргает (кадр «blink») и подпрыгивает (spring) после хорошего решения, тень под ним сжимается в прыжке | `ui/App.kt`, `ui/PetView.kt`, `StatRow` |
| Питомец | Объёмные пререндеренные спрайты (Blender, Cycles): мягкий свет, подповерхностное рассеивание, глянец — «игрушечный» вид в духе 3D-обложки ТЗ. 9 обликов × 3 стадии (без аксессуара → бандана → корона) × 4 выражения. Одна камера для всех кадров, чтобы смена вида или стадии не «дёргала» экран | `tools/art/pet.py`, `tools/art/import_sprites.sh`, `ui/PetSprites.kt` |
| Иконки | Material Symbols (`material-icons-extended`) для навигации и действий; эмодзи — только для игрового контента (товары, цели, категории) | все экраны |

## Компоненты M3 по экранам

| Экран | Компоненты |
|---|---|
| Оболочка | `NavigationSuiteScaffold`: `NavigationBar` (5 разделов: Питомец, План, Магазин, Копилка, Задания) на телефоне, `NavigationRail` при ширине ≥ 600 dp; `Badge` с числом открытых заданий; `TopAppBar` с действиями (прогресс, подсказка, замок взрослого) |
| Питомец (главный) | Hero-карточка: питомец на Canvas, `AssistChip` стадии, три `LinearProgressIndicator` показателей; две тональные карточки «Монеты»/«Копилка»; карточка цели; карточка «Сейчас» с одним следующим шагом; `ExtendedFloatingActionButton` «Завершить неделю» появляется после подтверждения плана |
| План | Карточки направлений с `FilledTonalIconButton` ±10 и индикатором доли; итоговая карточка; `Button` подтверждения; после подтверждения — таблица план/факт с иконками ✓/⚠ |
| Магазин | `SingleChoiceSegmentedButtonRow` (обязательное/желаемое), `AssistChip` с балансом в app bar, карточки товаров с эмодзи в тональном круге, `Button`/`OutlinedButton`, история покупок как `ListItem` |
| Копилка | Hero-карточка `tertiaryContainer`, карточка цели с прогрессом и сроком, `FilterChip` сумм, `Button` «Отложить» / `OutlinedButton` «Забрать» с предпросмотром в `AlertDialog` |
| Задания | Секции тем с иконкой в круге, карточки с `FilledTonalButton` «Решить», выполненные — `ListItem` с `CheckCircle`; экран задания: карточка ситуации, варианты — `OutlinedButton` во всю ширину, числовой ответ — `OutlinedTextField` |
| Прогресс / Справка | Карточки стадии и целей, индикаторы по темам, журнал монет `ListItem` + `HorizontalDivider`, глоссарий `ListItem` |
| Итог недели | Три строки с `CheckCircle`, таблица план/факт, карточка объяснений, кнопка «Дальше» |
| Для взрослого | Карточка-барьер с `OutlinedTextField` и `supportingText` ошибки; панель: `ListItem` + `Switch` для настроек, кнопки сброса с `AlertDialog` подтверждения |
| Диалоги | `AlertDialog` с иконкой, заголовком `headlineSmall`, списком объяснений и кнопкой 56 dp |

## Ключевые UX-решения

| Решение | Зачем |
|---|---|
| Нижняя навигация из 5 разделов вместо сетки кнопок | Стандартный паттерн Android, всегда на месте, бейдж подсказывает, что есть задания (ТЗ 2.5.3, 8.4) |
| Карточка «Сейчас» с одним следующим шагом: план → еда → уход → цель → копилка → задание → итог | Ведёт по игровому циклу без инструкции |
| FAB «Завершить неделю» появляется только после подтверждения плана | Главное действие заметно, но не раньше, чем составлен план |
| Питомец крупно, с именем, стадией и объяснением настроения рядом; показатели подписаны словом, числом и иконкой | Ресурсы видны сразу (2.5.3); цвет — не единственный сигнал |
| ±10 кнопками вместо слайдера | Крупные цели нажатия, круглые числа |
| Диалог перед покупкой: цена, категория, эффект, что останется | Осознанный выбор (2.5.6) |
| При нехватке монет — не «нельзя», а «не хватает N, вот варианты» | Ошибка становится учебной ситуацией (2.5.6, 8.4) |
| Итог недели: три галочки + таблица план/факт + объяснения | Объяснимость (2.2) |
| Питомец никогда не болеет и не умирает; показатели ≥ 10; рост не откатывается | Безопасная ошибка, без тревоги (2.2, 3.5) |
| Подсказки имён чипами | Дети 7 лет медленно печатают |
| Раздел для взрослого за примером на умножение | Простой барьер без пароля (2.5.12) |

## Доступность

| Требование ТЗ 3.6 | Реализация |
|---|---|
| Короткие фразы, простые слова, объяснение терминов | Тексты 1–2 предложения; справка с 10 терминами |
| Понятно, что делать в разделе | Заголовок в app bar, одна главная кнопка, карточка «Сейчас» |
| Интерактивные элементы ≥ 48 × 48 dp | Кнопки 56 dp, иконки-кнопки 48 dp, чипы 48 dp, элементы навигации 80 dp |
| Основной текст ≥ 16 sp, масштабирование | bodyLarge 18 sp, bodyMedium 16 sp; размеры в sp, экраны прокручиваются при системном увеличении шрифта |
| Цвет — не единственный сигнал | Категории подписаны текстом и иконкой; показатели — подпись + число + полоса; план/факт — ✓/⚠ рядом с числом; выражение питомца — форма рта, слёзы, текст причины |
| Контраст, единая навигация, кнопка возврата на одном месте | Пары цветов M3 (контраст ≥ 4.5:1 для текста); стрелка «назад» всегда слева в app bar; нижняя панель одинакова на всех основных экранах |
| Звуки и анимации можно отключить; важное не только звуком | Звуков нет; анимации питомца отключаются в разделе для взрослого |
| Подтверждение действий, меняющих прогресс | Покупка, снятие из копилки, получение цели, завершение недели, сброс и удаление профиля — диалог с «Отмена» |
| Тёмная тема | Следует системной настройке; все цвета из токенов, питомец и монета — фиксированные |
| Ориентация и планшеты | Портрет и альбом; при ширине ≥ 600 dp навигация становится рейлом, контент ограничен 640 dp |

TalkBack: у всех иконок-кнопок есть `contentDescription`, у питомца — описание «имя, стадия», у полос показателей — «Сытость 70 из 100».

## Самопроверка соответствия M3

| Категория | Оценка | Комментарий |
|---|---|---|
| Токены цвета | 9/10 | Все поверхности и текст — роли `MaterialTheme.colorScheme`; фиксированные цвета только у арта питомца и монеты |
| Типографика | 9/10 | Роли M3, шкала увеличена осознанно под возраст |
| Форма | 9/10 | Токены `MaterialTheme.shapes`; кнопки «pill» по умолчанию |
| Возвышение | 10/10 | Тональные контейнеры, тени только у FAB и диалогов (стандарт) |
| Компоненты | 9/10 | Только Material3-композаблы; питомец — собственный Canvas |
| Раскладка | 8/10 | Сетка 8 dp, ограничение ширины, одна колонка на телефоне; на планшете двухпанельные раскладки не используются |
| Навигация | 9/10 | Bar/Rail по классу окна, предсказуемый «назад» |
| Движение | 8/10 | Emphasized-переходы и spring у питомца; `MotionScheme` недоступен в 1.4.0 (internal) |
| Доступность | 9/10 | Описания, цели ≥ 48 dp, контраст из токенов |
| Тема | 9/10 | Светлая и тёмная схемы из палитры шаблона ЛЦТ; динамический цвет отключён намеренно (бренд и предсказуемость демо) |
