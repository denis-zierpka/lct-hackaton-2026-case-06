# UX и доступность — вариант game

Сдаётся вариант `game` (`ru.finny.pet`, 1.3.0): комната с питомцем, разделы открываются
панелями поверх комнаты, есть мини-игра. Здесь описан только он. Вариант `classic` лежит в
репозитории, но в сдачу не входит.
Требования: ТЗ 3.6 (UX и доступность), 3.1.2 (портрет от 360 dp), 2.5.3 (главный экран),
2.5.12 (раздел для взрослого).

Клетка поля мини-игры — `min(ширина / 7, высота / 6)`. На 411 × 914 dp она около 56 dp.
В портрете 360 × 640 поле делит высоту с колонкой кнопок, и по расчёту раскладки клетка
около 27–30 dp. Это оценка, на экране не замерялась. Смягчает: ход можно сделать двумя
касаниями или свайпом, а мини-игра необязательна — учебный цикл проходится без неё.
Исправить к финалу: в узком портрете поставить кнопки мини-игры в ряд.

Проверка на экране: в [`GameTheme.kt`](../app/src/game/java/ru/finny/pet/game/ui/GameTheme.kt)
`labelMedium` и `labelSmall` — 14 sp, `bodySmall` — 16 sp. Поиск `labelMedium|labelSmall` по
`app/src/game` находит только места из этой таблицы (с 2026-09-26 — и debug-макет `game/mock`,
его строки тоже в таблице).

**Масштаб шрифта.** Размеры заданы в sp, панели прокручиваются, системный масштаб
действует на них полностью. У комнаты и мини-игры геометрия фиксированная, поэтому
`SceneFontScale` ограничивает для них масштаб значением 1,3. Окна обратной связи поверх
комнаты под это ограничение не попадают. Боковые панели комнаты в альбоме шириной
170–240 dp растут вместе со шрифтом, фразы переносятся.

## Цвет — не единственный признак

| Что передаётся | Чем кроме цвета |
|---|---|
| Выбранный вариант: вид, цвет, имя, вкладка магазина, сумма копилки, своя цель и цена | значок «✓» (`CheckBadge`), рамка; `selectable(role = Role.RadioButton)` — TalkBack говорит «выбрано» |
| Выбранная клетка мини-игры | рамка и увеличение ×1,12 |
| Категория расхода | слово («Обязательное» / «Желаемое» / «Копилка») и своя крышка банки |
| План/факт, итог недели | «✓» или «!» в круге, числа «план · факт», штампы «✓» / «–» со строкой текста |
| Состояние питомца | выражение мордочки (довольный, спокойный, грустный), три полосы с иконкой и числом, причина настроения текстом по касанию (2.5.10) |
| Ошибка | окно «Пока не получится» с грустным питомцем, причина и строки «Вариант: …» |
| Не хватает монет | подпись «не хватает», бледная картинка, серый ценник |
| Мини-игра закрыта | кнопка приглушена; при нажатии окно «Пока рано» с причиной; TalkBack — «Игра, закрыто до плана» |
| Выполненное задание | «✓» — верно, «·» — попытка, награда числом |

## Звук и анимации

Переключатели — в разделе для взрослого, блок «Настройки». Сброс и удаление профиля их
сохраняют (`Economy.resetProfile`, `deleteProfile`).

| Переключатель | По умолчанию | Что делает |
|---|---|---|
| «Звуки» — «Эффекты при действиях» | вкл. | 13 коротких эффектов (`SoundPool`, `Sfx.play`) |
| «Музыка» — «Фоновая мелодия» | **выкл.** | одна мелодия по кругу, громкость 0,35; на титульном экране не играет, при сворачивании приложения ставится на паузу |
| «Анимации» — «Движение питомца и эффекты» | вкл. | гасит всё движение через `LocalAnimate`; при системном запрете анимаций тумблер неактивен, подпись — «Выключены в настройках Android» |

**Анимации.** `LocalAnimate = state.animations && ANIMATOR_DURATION_SCALE > 0`. Системную
настройку («Отключить анимацию» в специальных возможностях или «Масштаб длительности
анимации = 0») игра перечитывает при каждом возврате в приложение. Тумблер показывает выбор
взрослого (`state.animations`). Если анимации выключены системно, тумблер неактивен и подписан
«Выключены в настройках Android» — нажатие ничего не меняет. При `LocalAnimate = false` отключаются:
- переходы между экранами и появление окон (`orNone()`);
- частицы: монеты, конфетти, сердечки, искры (`ParticleController.enabled`);
- дыхание, моргание, прыжок и действия питомца (`PetSprite(animate)`);
- «печатающийся» текст — фраза показывается сразу;
- нажатие кнопок, полосы, счётчики HUD, наполнение банок — меняются мгновенно (`snap()`);
- мини-игра: обмен, падение и появление фишек — сразу на месте;
- итог недели: штампы появляются все сразу, без поочерёдного показа.

**Важное не только звуком.** Звук всегда сопровождает видимое событие:

| Звук | Что видно одновременно с ним |
|---|---|
| неудача (`FAIL`) | окно «Пока не получится» / «Пока рано» с причиной; при неверном ответе на вопрос питомца — объяснение текстом в пузыре |
| успех (`SUCCESS`), фанфары | окно с результатом, штамп «✓», надпись «{имя} вырос!» |
| монета (`COIN`) | покупка, копилка, бонус взрослого — окно с новыми числами («Баланс: −…», «В копилку: +…») и запись в «Откуда монеты на этой неделе»; «+» в банке плана — новое число в банке и «В кошельке: N из M» (в журнал не пишется) |
| пузырь (`BUBBLE`) | реплика питомца текстом |

## Навигация и «Назад»

Кнопка «Назад» — круг со стрелкой в левом верхнем углу (`CloseButton`) на всех панелях, а
также в знакомстве, создании питомца и мини-игре. Заголовок панели сдвинут вправо, чтобы
не перекрывать её. Куда ведут экранная стрелка и системный «Назад» (`GameViewModel.back()`):

| Экран | Куда ведёт «Назад» |
|---|---|
| Титульный, комната | системный «Назад» закрывает приложение (корень), если не открыто окно или вопрос питомца — тогда закрывает их |
| Знакомство | в комнату, если питомец есть, иначе на титул |
| Создание питомца | на титул |
| План, Магазин, Копилка, Задания, Прогресс | в комнату |
| Для взрослого | в комнату, если питомец есть, иначе на титул (раздел открывается и с титула без профиля) |
| Задание | к списку заданий |
| Справка | в «Прогресс» |
| Итог недели | в комнату; на экране — кнопка «Дальше, к неделе N+1» |
| Мини-игра | если открыт вопрос питомца, системный «Назад» сначала закрывает его. Стрелка («Закончить») и системный «Назад» открывают панель «Игра окончена» со счётом; следующее «Назад» или «Забрать монеты» начисляют монеты и ведут в комнату. Выйти без итога нельзя: использованные бомбочки списываются |

Из комнаты в основные разделы — одно касание: 5–6 кнопок внизу, 3 иконки вверху и кнопка
«Сейчас». Шаги по порядку (`nextStep()`): план → еда → уход → цель → копилка → задание →
конец недели. Шаг «копилка» — только если на балансе есть хотя бы наименьшая сумма из
`rules.savingsAmounts`, иначе кнопка ведёт к следующему доступному шагу.

**Окна модальны.** Подтверждения (`ConfirmPanel`), окно результата (`FeedbackOverlay`), панель
«Игра окончена» и вопрос питомца в мини-игре лежат на затемнении, которое не пропускает касания
к экрану под ним. Системный «Назад» закрывает открытое окно (в любом экране, в том числе в
комнате), а не экран и не приложение. Для TalkBack окно — отдельная панель: `paneTitle` с его
заголовком, заголовок отмечен как `heading`.

## Экран и ориентация

- **Портрет от 360 dp (3.1.2).** Главный экран — одна колонка без наложений (2.5.3): монеты
  и копилка → имя, стадия, три показателя → питомец с пузырём → «Сейчас» → цель → кнопки
  разделов. Панели в портрете — одна колонка (`Adaptive`), карточки товаров и целей —
  по две в ряд.
- **Альбом.** Питомец в центре, показатели слева, цель и кнопка шага с подписью «Сейчас» справа.
  Пузырь питомца — по высоте текста и кнопок ответа, не выше половины сцены, в полосе между
  HUD и кнопками разделов; не помещается — прокручивается внутри пузыря. Копилка, прогресс, задание и раздел для взрослого — в две колонки (`Adaptive`). Смена ориентации не перезапускает экран: `configChanges` в манифесте, состояние

## Тексты для ребёнка

- **Без упрёка (3.5).** Ошибка — «Пока не получится» и варианты, как поправить. Знакомство
  говорит: «Ошибаться можно!». Предупреждения о конце недели звучат как факт: «Еда на этой
  неделе ещё не куплена — {имя} проголодается.» Питомец грустит, но не болеет. К концу недели
  показатели не опускаются ниже 10 (`rules.statFloor`), рост не откатывается.
- **Без рода ребёнка.** Безличные формы: «отложено», «потрачено», «Этот вопрос уже решён».
  Проверка: `grep -rnE '(Ты|ты) [а-яё]*(л|лся)([^а-яё]|$)' app/src/game/java` ничего не находит
  (граница слова в конце нужна, иначе ловится «ты получаешь»).
  Тексты правил проверяют тесты `MvpRulesTest` («…без рода»). О питомце тексты написаны в
  мужском роде («питомец») — ограничение прототипа.

## Раздел для взрослого (2.5.12)

- **Вход** — «Для взрослого» на титуле или замок в комнате.
- **Барьер** — пример «двузначное × однозначное»: `a × b`, a от 12 до 19, b от 3 до 9. После
  ошибки — новый пример (всегда другой) и пустое поле. После верного ответа клавиатура прячется,
  поле очищается. Пройденный барьер не переживает перезапуск процесса (`unlocked` — `remember`):
  после возврата в приложение, убитое системой, пример нужно решить снова. Поворот экрана вход не
  сбрасывает (`configChanges`).
- **Внутри:**
  - чему учит игра — 5 целей из рамки компетенций;
  - прогресс без оценок ребёнка: стадия, недели, цели, полосы по темам;
  - бонус ребёнку: 4 причины, до 3 раз в неделю по 10 монет, каждое начисление через
    подтверждение и с записью в журнале;
  - четыре переключателя: «Звуки», «Музыка», «Анимации», «Демо-режим»;
  - действия с профилем через подтверждение; окна открываются по центру экрана при любой
    прокрутке раздела, «Сбросить профиль?» называет, что обнулится: питомец, прогресс, покупки,
    копилка (настройки остаются);
  - версия (`BuildConfig.VERSION_NAME` — 1.3.0).

## TalkBack

| Элемент | Что слышно |
|---|---|
| Кнопки комнаты и HUD | название: «План», «Прогресс», «Взрослым»; «Игра, закрыто до плана»; с бейджем — «Задания, 8» |
| Счётчики HUD | «Монеты 120», «Копилка 30» — один узел, число не повторяется |
| Строка цели в комнате | «Цель: Самокат, накоплено 10 из 150 монет» — одним описанием |
| Полосы | «Сытость 70 из 100»; если числа уже есть в подписи («Сбережения: 1 из 3») — читается подпись |
| Питомец (кнопка) | «{имя}, {стадия}. {причина настроения}» |
| Карточка товара / цели | «{название}, {цена} монет, {эффект}», если денег мало — «…, не хватает» / «{название}, {цена} монет» |
| Варианты выбора | название и «выбрано» (`Role.RadioButton`) |
| «Назад» | кнопка «Назад», в мини-игре — «Закончить» (`contentDescription` и `onClickLabel`) |
| Переключатели настроек | строка целиком: подпись, подсказка и «вкл./выкл.», роль «переключатель» (`toggleable(role = Role.Switch)`) |
| Окна | объявляются как панель по заголовку (`paneTitle`), заголовок — `heading` |

Поле мини-игры под TalkBack не адаптировано: фишки подписаны («монета», «яблоко»…), но ход
делается касанием или жестом по полю. Полный прогон с TalkBack не проводился.
