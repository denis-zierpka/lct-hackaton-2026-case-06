# План работ — «Питомец Финни»

Статус: живой документ, обновляется по ходу итераций.

## Решения (зафиксированы)

| Вопрос | Решение | Почему |
|---|---|---|
| Стек | Kotlin + Jetpack Compose (Material 3), один Gradle-модуль `app` | Нативный Android, минимум зависимостей, стабильная сборка APK |
| Хранение | JSON-файл `state.json` в `filesDir` через kotlinx.serialization | ТЗ допускает файловое хранилище; логика тестируется на JVM без Android |
| Контент | JSON в `assets/content/` (задания, товары, цели, глоссарий, конфиг) | Новое задание = новая запись в JSON, код не меняется (п. 2.5.14) |
| Игровой период | «Неделя»; завершается кнопкой, без привязки к реальному времени | Демо-режим и обычный режим используют один цикл; требования 2.5.13 и 2.6 |
| Демо-режим | Флаг в состоянии: все задания открыты сразу, тестовый профиль сбрасывается из раздела для взрослого | п. 2.5.13, 2.5.8 |
| Навигация | Состояние экрана в ViewModel + `BackHandler` | Без navigation-compose, меньше зависимостей |
| Питомец | Рисуется на Canvas: 3 вида × 3 цвета = 9 комбинаций, 3 стадии, 3 выражения | Без сторонних ассетов и лицензионных вопросов |
| Сервер, ИИ | Нет | Не требуются ТЗ (п. 3.2) |
| Подпись | Ключ вне репозитория, `keystore.properties` в `.gitignore` | п. 3.4 — секретов в репозитории нет |

## Этапы

1. ✅ Окружение: JDK 17, Android SDK 36, эмулятор.
2. ✅ Скелет проекта Gradle, сборка пустого приложения.
3. ✅ Домен: модели, экономика (план, покупки, накопления, задания, конец периода, рост), 25 тестов на JVM.
4. ✅ Контент: 9 комбинаций питомца, 10 товаров, 4 цели + своя, 10 заданий по 3 темам, глоссарий.
5. ✅ UI: знакомство, создание питомца, главный экран, план, магазин, копилка, задания, прогресс, справка, итог недели, раздел для взрослого.
6. ✅ Прогон сквозного сценария (Приложение А) на эмуляторе, скриншоты, видео (`tools/demo_run.sh`).
7. ✅ Ревью кода (субагент reviewer): раунд 1 — 4 CRITICAL + 12 MINOR исправлены; раунд 2 — см. журнал ниже.
8. ✅ Релизная сборка: подписанный APK (R8), проверка установки и сценария на минифицированной сборке.
9. ✅ Документация: README, docs/*, DOCX, презентация PPTX, карточка RuStore, иконка 512×512.

## Известные ограничения на старте

- Проверка на физическом устройстве недоступна в этой сессии; отчёт содержит результаты на эмуляторе (arm64, Android 16 / API 36).
- Публикация в RuStore не выполняется (п. 2.7.4).
