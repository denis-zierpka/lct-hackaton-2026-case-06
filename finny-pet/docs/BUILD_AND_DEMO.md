# Сборка, запуск, демонстрационный режим

## Требования к окружению

| Инструмент | Версия | Примечание |
|---|---|---|
| JDK | 17 (проверено на OpenJDK 17.0.20) | JDK 21 тоже подходит; JDK 26 — нет |
| Android SDK | platforms;android-36, build-tools;36.0.0, platform-tools | устанавливается `sdkmanager` |
| Gradle | 9.4.1 через `./gradlew` (скачается сам) | |
| Android Gradle Plugin | 9.2.1 | указан в `build.gradle.kts` |
| Kotlin | 2.4.20 (встроенный в AGP) | |

Android Studio не обязательна.

## Быстрая сборка

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 17)   # macOS; на Linux укажите путь к JDK 17
export ANDROID_HOME=~/Library/Android/sdk           # или путь к вашему SDK
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Релизная сборка (подписанный APK)

1. Создайте ключ вне репозитория (один раз):

```bash
keytool -genkeypair -v -keystore ~/.finny-keys/finny-release.jks -alias finny \
  -keyalg RSA -keysize 2048 -validity 10000
```

2. Скопируйте `keystore.properties.example` в `keystore.properties` (файл в `.gitignore`) и заполните путь и пароли. Альтернатива — переменные окружения `FINNY_STOREFILE`, `FINNY_STOREPASSWORD`, `FINNY_KEYALIAS`, `FINNY_KEYPASSWORD`.

3. Соберите и проверьте подпись:

```bash
./gradlew :app:assembleRelease
$ANDROID_HOME/build-tools/36.0.0/apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```

Результат: `app/build/outputs/apk/release/app-release.apk` (~1,8 МБ, R8; из них ~0,7 МБ — шрифт Montserrat). Без `keystore.properties` release подписывается отладочным ключом — сборка предупредит об этом.

AAB при необходимости: `./gradlew :app:bundleRelease`.

## Установка

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
adb shell am start -n ru.finny.pet/.MainActivity
```

Или скопируйте APK на телефон и установите вручную (нужно разрешить установку из неизвестных источников).

## Перерендер спрайтов питомца (по желанию)

Спрайты уже лежат в репозитории. Чтобы изменить модель, поправьте `tools/art/pet.py` и выполните (нужен Blender 4.x/5.x):

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/art/pet.py -- --all /tmp/pets --size 512
tools/art/import_sprites.sh /tmp/pets
```

Первая команда рендерит 108 кадров (около 15 минут на Apple GPU), вторая конвертирует их в WebP и обновляет `ui/PetSprites.kt`.

## Демонстрационный режим и тестовый профиль

Игровая неделя в приложении завершается кнопкой «Завершить неделю» и не привязана к календарю, поэтому все этапы цикла проходятся подряд.

Подготовка тестового профиля:

1. На любом экране откройте «Для взрослого» (на экране знакомства — кнопка внизу; на главном — «🔒 Для взрослого»).
2. Решите пример на умножение.
3. Нажмите «Создать тестовый профиль (демо)» → «Да, продолжить». Включится демо-режим (все 10 заданий открыты сразу), прогресс обнулится, приложение вернётся к экрану знакомства.
4. Пройдите сценарий ниже.

Сброс к исходному состоянию: тот же раздел → «Сбросить профиль» (демо-режим сохраняется) или «Удалить профиль и данные».

## Сквозной сценарий (Приложение А ТЗ)

| № | Шаг | Что нажать |
|---|---|---|
| 1 | Первый запуск | Знакомство: «Дальше» × 2 |
| 2 | Профиль | «Создать питомца» |
| 3 | Питомец | Вид, цвет, имя (чип «Финни» или свой) → «Начать игру» |
| 4 | Стартовый бюджет | Диалог «+100 монет» → «Понятно»; главный экран |
| 5 | План | «Составить план» → +10 до 50 / 20 / 30 → «Подтвердить план» |
| 6 | Задание | «⭐ Задания» → «Решить» → выбрать ответ или ввести число → объяснение |
| 7 | Покупки | «🛒 Магазин» → «Корм» → «Купить»; «Бантик» → «Купить»; «Домик-палатка» → «Не хватает» — объяснение с вариантами |
| 8 | Цель и копилка | «🐷 Копилка» → «Копить на это» (Самокат) → «Отложить 20»; «Забрать 20» показывает предпросмотр — «Отмена» |
| 9 | Обратная связь | Диалоги после каждого шага; текст под питомцем |
| 10 | Следующая неделя | Главный → «Завершить неделю» → «Завершить» → экран итога → «Дальше». Повторить 2–3 раза: после 4 очков роста питомец станет «Подростком», после 9 — «Взрослым» |
| 11 | Перезапуск | Закрыть приложение, открыть — неделя, баланс, копилка, цель на месте |
| 12 | Взрослый | «🔒 Для взрослого» → пример → просмотр прогресса → «Сбросить профиль» |

Ориентировочное время демонстрации — 4–5 минут.

## Автоматический прогон на эмуляторе

`tools/ui.py` — вспомогательный скрипт на `adb` + `uiautomator` (тап по тексту, скриншоты), использованный для проверки сценария и записи скриншотов:

```bash
python3 tools/ui.py tap "Дальше" \; tap "Дальше" \; tap "Создать питомца" \; shot create_pet
```
