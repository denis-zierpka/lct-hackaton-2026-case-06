# Тест-кейсы и отчёт о проверке

ТЗ 5, п. 10: набор тест-кейсов и отчёт о проверке на физическом устройстве. ТЗ 3.4: ключевая
логика бюджета, списаний, накоплений и прогресса покрывается автотестами или тест-кейсами.

Проверяется сдаваемый вариант `game` (`ru.finny.pet`, 1.3.0, versionCode 4). Вариант `classic`
в сдачу не входит: для него запускаются только автотесты (они общие).

## Автотесты

JVM-тесты чистой логики `domain/` лежат в [`app/src/test/java/ru/finny/pet/domain/`](../app/src/test/java/ru/finny/pet/domain/).
Они читают настоящий [`content.json`](../app/src/main/assets/content/content.json), поэтому правка
контента или чисел экономики тоже проверяется. Интерфейс автотестами не покрыт, его проверяют
ручные TC ниже.

Всего 117 тестов, одинаковых для обоих вариантов. Прогон 2026-09-25 (после MVP-T11): 117 из 117
в `game` и в `classic`, падений 0.

установка или «Для взрослого» → «Удалить профиль и данные». Демо-режим выключен (он выключен
по умолчанию), поэтому на неделе 1 открыто 6 заданий из 10. Числа баланса ниже рассчитаны на
прохождение шагов по порядку. Мини-игра и бонус (TC-14, TC-16) меняют баланс, поэтому их
проходят после сквозного сценария.

## Отчёт с физического устройства

ТЗ 3.1.3 требует проверки хотя бы на одном физическом устройстве с ОЗУ от 3 ГБ. Первый прогон —
2026-09-25, сквозной сценарий Приложения А (шаги 1–12) через `adb` с телефона, подключённого к
машине разработки; звук на время прогона выключен (громкость медиа 0), поэтому звук, музыку и
плавность на глаз проверяет команда. Скриншоты — [`screenshots/device/`](../screenshots/device/).

```
adb install -r finny-pet/release/finny-pet-1.3.0-release.apk
adb shell am force-stop ru.finny.pet
adb shell am start -W -n ru.finny.pet/.MainActivity   # TotalTime, повторить 3 раза
```
