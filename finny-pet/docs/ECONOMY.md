# Игровая экономика: формулы и правила

Все правила реализованы в одном классе `app/src/main/java/ru/finny/pet/domain/Economy.kt` (чистый Kotlin, без Android) и покрыты тестами `app/src/test/java/ru/finny/pet/domain/EconomyTest.kt`. Числовые параметры лежат в `app/src/main/assets/content/content.json` → `rules` и могут меняться без правки кода.

## Валюта и доход

| Параметр | Значение | Где |
|---|---|---|
| Игровая валюта | монеты 🪙, реальной стоимости не имеют | — |
| Карманные деньги | +100 в начале каждой игровой недели (и при создании питомца) | `rules.allowance` |
| Награда за задание | +20 за верный ответ, +5 за попытку; каждое задание решается один раз | `rules.rewardCorrect`, `rules.rewardWrong` |

Каждое начисление и списание записывается в журнал недели (`GameState.ledger`) с источником и суммой: «Карманные деньги на неделю +100», «Задание „Соблазн“ +20», «Покупка: Корм −30», «В копилку −20», «Остаток с прошлой недели +5». Сумма записей журнала всегда равна балансу (тест `period end requires plan and scores three rules`).

## План личного бюджета

- До начала недели ребёнок распределяет баланс по трём направлениям: обязательное `M`, желаемое `O`, копилка `S`.
- Ограничение: `M + O + S ≤ balance`, все значения ≥ 0. Остаток `balance − (M+O+S)` показывается как «вне плана».
- Шаг изменения — 10 монет; кнопка «+10» недоступна, если остаток меньше 10.
- Подтверждённый план не меняется до конца недели. Покупки и пополнение копилки возможны только после подтверждения (снятие из копилки — всегда, это способ профинансировать план).

## Покупки

- Условие: `price ≤ balance`. Иначе покупка не выполняется, а приложение показывает, сколько не хватает, и варианты: выполнить задание, более дешёвый товар той же потребности, взять из копилки (с предупреждением, что цель отодвинется), дождаться новой недели.
- Эффект: `balance −= price`; показатели питомца `hunger/clean/mood += effect`, каждый ограничен диапазоном `[0, 100]`.
- После покупки показывается сравнение факта с планом по категории: «На желаемое потрачено 25 из 20 по плану — больше, чем планировал».

## Копилка и цель

- Пополнение: `amount ≤ balance` → `balance −= amount`, `savings += amount`, `depositedThisPeriod += amount`.
- Снятие: `amount ≤ savings` → обратная операция, `withdrawnThisPeriod += amount`. Перед подтверждением показывается предпросмотр: сколько останется, сколько будет не хватать до цели, как изменится срок.
- Факт накоплений за неделю: `factSavings = deposited − withdrawn`.
- Цель достигнута, когда `savings ≥ goal.price`; по отдельному подтверждению: `savings −= price`, цель переходит в «достигнутые», `mood += 30`.
- Средний взнос за неделю: `avg = (Σ история + текущая неделя) / (число завершённых недель + [текущая неделя > 0])`. Текущая неделя учитывается только если в неё уже что-то отложено, чтобы прогноз не «удваивался» каждый понедельник.
- Срок: `eta = ceil((price − savings) / avg)` недель; если `avg = 0`, срок не показывается («Откладывай регулярно — и я посчитаю»).

## Конец игровой недели

Требуется подтверждённый план. Три проверки:

| Проверка | Условие |
|---|---|
| Еда и уход куплены (`mandatoryCovered`) | за неделю куплен хотя бы один товар с потребностью `FOOD` и хотя бы один с `CARE` |
| Траты по плану (`planKept`) | `factM ≤ M` и `factO ≤ O` и `factSavings ≥ S` |
| Копилка выросла (`saved`) | `factSavings > 0` |

`score = число выполненных проверок` (0–3).

Изменение состояния питомца (порядок применения):

1. Естественное убывание: `hunger −30`, `clean −25`, `mood −10`.
2. Если обязательное не закрыто: `mood −20`; нет еды → `hunger −20`; нет ухода → `clean −20`.
3. `planKept` → `mood +10`; `saved` → `mood +10`.
4. Все показатели ограничиваются диапазоном `[10, 100]`: нижняя граница 10 исключает «смерть» и запугивание.

Рост: `growth += score`, никогда не уменьшается («безопасная ошибка»).

| Стадия | Очки роста |
|---|---|
| Малыш | 0–3 |
| Подросток | 4–8 |
| Взрослый | 9 и больше |

Новая неделя: `period += 1`, `balance += 100`, план сбрасывается, история покупок недели очищается, `depositHistory += factSavings`, итог недели сохраняется в `history`.

## Настроение и выражение питомца

`min = min(hunger, clean, mood)`, `avg = (hunger + clean + mood) / 3`:

- `min < 30` → грустный (одна забытая потребность важнее игрушек);
- `avg ≥ 60` и `min ≥ 40` → довольный;
- иначе → спокойный.

Под питомцем всегда есть текстовое объяснение причины: «Финни голодный — помоги ему».

## Задания

- Нормальный режим: задание доступно с недели `unlockPeriod` (1–4).
- Демо-режим (`GameState.demo = true`): все задания доступны сразу.
- Верный ответ дополнительно даёт `mood +5`.

## Пример прохождения (демо-сценарий, неделя 1)

```
Старт: баланс 100, копилка 0, питомец 70/70/70
План: 50 / 20 / 30
Корм −30 (сытость +40 → 100), Шампунь −20 (чистота +40 → 100), Бантик −15 (настроение +10 → 80)
Задания: +20, +20 → баланс 75
Копилка +20 → баланс 55, копилка 20, цель «Самокат» 150: осталось 130, ≈7 недель
Конец недели: еда и уход ✓, план ✗ (копилка 20 < 30), копилка ✓ → рост +2
Питомец: 100−30=70 / 100−25=75 / 80+5−10+10=85 → 90 с учётом бонусов, довольный
Неделя 2: баланс 55 + 100 = 155
```
