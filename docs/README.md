# Документация проекта

Приложение «Питомец Финни» — игровой сервис для формирования базовых финансовых
навыков у детей 7–11 лет. Кейс 06, ЛЦТ 2026, Департамент финансов города Москвы.

## Состав

| Файл | Что внутри |
|---|---|
| `competencies.md` | Карта образовательных компетенций: шесть результатов из ТЗ, привязанные к дословным формулировкам Единой рамки |
| `sources/` | Исходные документы заказчика в оригинале и в виде текста для поиска |

### Единая рамка компетенций

`sources/Единая_рамка_компетенций_ФГ_2026.pdf` — оригинал, 33 страницы формата A3.
`sources/Единая_рамка_текст.txt` — извлечённый текст.

Утверждена протоколом шестого заседания Межведомственной координационной комиссии
от 5 марта 2026 г. Документ охватывает четыре уровня образования; нам нужна
**Таблица 1, начальное общее образование, 7–11 лет** — строки 20–401
в извлечённом тексте.

Разбор и привязка к нашим механикам — в `competencies.md`.

## Как извлекался текст

```
pdftotext -layout исходный.pdf результат.txt
```

Ключ `-layout` обязателен: без него таблицы рамки превращаются в кашу
и столбцы «базовый уровень» и «продвинутый уровень» перемешиваются.

## Замечание о точности цитат

При работе с требованиями заказчика ссылки даются на номер раздела
и дословную формулировку. Пересказ по памяти приводит к потере оговорок —
например, в ТЗ 2.5.7 расчёт срока достижения цели обязателен не всегда,
а только «если приложение показывает срок».
