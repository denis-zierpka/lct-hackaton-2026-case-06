## CONTRACT
1. **Мини-игра закрыта до плана.** `GameViewModel.startMiniGame()`: если
   `economy.miniGameLock(state) != null` — `Feedback("Пока рано", [<текст блокировки>,
   "Вариант: Открой «План» в комнате"], Mood.OOPS)`, экран не меняется; иначе новая
   игра с `seed = System.nanoTime()`. Кнопка «Игра» в комнате при блокировке остаётся
   нажимаемой (объяснение важнее), но выглядит приглушённо (alpha 0.5) и несёт в
   `contentDescription` «закрыто до плана».
2. **Системный «Назад» в мини-игре = «Закончить».** Пока идёт раунд — открывает панель
   «Игра окончена» (как крестик); на открытой панели — `finishMiniGame()`. Бомбы
   списываются, выход без начисления невозможен. `vm.back()` для `Screen.MiniGame`
   ничего не делает (обрабатывает экран). `quitMiniGame()` удалить.
3. **Выигрыш мини-игры** = баланс после − баланс до `finishMiniGame`; монеты летят и звучит
   SUCCESS только при выигрыше > 0.
4. **Прыжок и действие питомца не повторяются** при возвращении в комнату: проигрывается
   только событие, случившееся после последнего показа (ключ «уже показан» живёт вне
   экрана, например в `PetActionState`). Новое событие (покупка, верный ответ, цель) — играет.
5. **Подсказка из комнаты:** «Назад»/крестик в Intro при существующем профиле → Room
   (сейчас → Title и музыка обрывается). Без профиля — Title, как сейчас.
6. **Звук и музыка раздельно.** В разделе взрослого два переключателя: «Звуки» —
   «Эффекты при действиях» (`state.sounds`), «Музыка» — «Фоновая мелодия» (`state.music`,
   по умолчанию выключена). `Sfx`: отдельные флаги эффектов и музыки; музыка играет только
   при `music == true` и не на Title; `SoundPool.release()` при уходе из композиции.
   `setMusic(on)` в VM. Мёртвые `Sound.MUNCH`/`SPLASH` — либо проиграть при EAT/WASH,
   либо удалить вместе с файлами (выбери проигрывание: MUNCH при еде, SPLASH при уходе).
7. **Бонус взрослого** в разделе для взрослого (после барьера), блок «Бонус ребёнку»:
   - текст: `До {parentBonusPerPeriod} раз в неделю по {parentBonusAmount} монет — за дела, а не за оценки. Осталось на этой неделе: {parentBonusesLeft}.`
   - кнопки-причины из `content.parentBonusReasons` (≥ 48 dp); нажатие → подтверждение
     `ConfirmPanel("Начислить {A} монет?", ["За: «{причина}»", "Монеты появятся у ребёнка сразу, в журнале будет запись."])`
     → `vm.parentBonus(index)` → `Feedback` с сообщениями domain;
   - без профиля или при исчерпанном лимите кнопки неактивны, текст объясняет почему.
8. **Барьер для взрослого:** пример `a × b`, a ∈ 12..19, b ∈ 3..9; после неверного ответа —
   новый пример и очищенное поле.
9. **Версия** в разделе взрослого — `BuildConfig.VERSION_NAME`, без строки в коде.
10. **Активное задание на главном экране (2.5.3):** постоянная плашка «Сейчас: {nextStep().second}»
    (кнопка ≥ 48 dp), по нажатию — `nextStep().third` (для WeekEnd — открыть подтверждение
    конца недели). Портрет 360 dp — над карточкой цели, без наложений; альбом — в правой колонке
    под целью.
11. **Причина настроения (2.5.10):** нажатие на питомца, когда он не HAPPY, сначала показывает
    пузырь с `economy.faceReason(pet)`; следующее нажатие — как сейчас (вопрос или реплика).
    Когда HAPPY — как сейчас.
12. **Числа из rules:** шаг плана — `rules.planStep`; суммы копилки — `rules.savingsAmounts`;
    «100 монет» в знакомстве — `rules.allowance`.
13. **VM после MVP-T01:** `createTestProfile` = `economy.newGame(demo = true, animations, sounds, music)`;

16. **Имена-подсказки** при создании питомца: «Финни», «Пушок», «Бублик» (вместо «Искра»):
