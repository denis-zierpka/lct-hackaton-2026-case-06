**Уроки сессии 6** (кандидаты в WORKFLOW, вместе с уроками сессии 5 ниже):
- Зелёная машинная приёмка арта ничего не говорит о виде: две панели независимых судей (4 линзы + синтезатор,
  каждая находка перепроверена по картинке) дали 12 + 8 правок после зелёной приёмки. Находки — файлом кодеру.
- Зонд сам врёт: композит «UI со снимка на новый фон» протекал (белое окно комнаты = белая карточка), не видел
  фон под подложкой Match3 α 0,18, а заливка «замкнутых дыр» съела всё поле. Самопроверка зонда — тождество:
  композит на фоне самой комнаты обязан совпасть со снимком (0 px > 12).
- Правки оркестратора в protect-путях между заходами кодеров — коммитить до `assert-oracle-intact`, иначе FAIL
  на своих же файлах.
- Blender не умеет оси вариативного шрифта: вывески — статическим экземпляром (fontTools instancer) + текст в
  меш с voxel-remesh (перекрытые контуры иначе дают швы и петлю в «Р»).
- Предложения судей проверять правилами задачи: «светлее» от арт-директора ломало ΔE ≥ 20 (жители сливались
  с питомцем). Владелец решает по картинке («без визуала не скажу») — варианты всегда листом.
- Для дизайн-решений — дизайн-панель: 3 независимых макета с разных углов (игра / педагогика / цена) на
  настоящем фоне S23 → 3 судьи → синтез → гибрид дорисовать и показать; владелец правит по макету (№ 39).
- Кодер на Opus xhigh (решение владельца: Blender без экономии модели) закрыл 12 визуальных правок за заход;
  на больших группах упирается в лимит — workflow продолжает новым кодером по дереву.

**Уроки сессии 5** (кандидаты в WORKFLOW):
- Зелёная машинная приёмка UI-задачи ничего не говорит о UI: живая проверка нашла 14 дефектов после
  кодеров 1–2 и ещё 8 после правки (регрессии), ревьювер — 2, которые пропустила живая. UI без живого
  замера и потоков из ACCEPTANCE не принимать.
- Переупорядочил вызовы в VM — проверь, что читает навигация: `navigate` до `commit` видел старое
  `asleep`, «Проснуться» после перезапуска не выводил из ночи (R1). Порядок: commit → переход → строки.
- Одна подпись — одна формула на всех экранах («Не разложено» считалось по-разному в листе кошелька).
- Доки, которые читатели готовят параллельно с кодером, описывают промежуточный код: после финального
  коммита кода — вторая сверка (нашла 81 правку из 391).
- Замер до оптимизации (S1f): план «IO + LRU + async save» не решал измеримой проблемы — отложен с
  условием включения и порогами. Эмулятор на swiftshader: p50 ≈ 32 мс в покое, доля janky там не порог.
- Кодер на длинной правке упирается в лимит ходов — продолжать через SendMessage.
- Критики спек арта (41 находка) поймали то, что я не видел: Blender выходит с кодом 0 при исключении
  (нужен `--python-exit-code 1`), печать «cycles device» — не доказательство GPU (зонд по состоянию +
  замер на тяжёлом кадре: smoke 512² упирается в запуск Blender), `git diff` не видит новых файлов
  (`git status -uall`), `sheets.py` растягивал квадраты, фон места почти весь закрыт UI (≈ 200 dp сверху,
  карточки с 31 %) — композицию проверять композитами по маске со снимков.

## Окружение (Windows 10, эта машина)

- JDK 17 Adoptium (`JAVA_HOME` задан), Android SDK — `%LOCALAPPDATA%\Android\Sdk`
  (platform 36, build-tools 36.0.0, emulator, образ android-36.1 google_apis x86_64),
  `finny-pet/local.properties` с `sdk.dir=C\:/Users/Singularity/AppData/Local/Android/Sdk`.
- Gradle: из `finny-pet/` — `./gradlew` в Git Bash или `.\gradlew.bat` в PowerShell. Из Python
  вызывать `gradlew.bat` по абсолютному пути: `bash` из Python попадает в WSL. Кодеров с Gradle —
  по одному.
- **Blender 5.2 LTS** — `C:/Program Files/Blender Foundation/Blender 5.2/blender.exe` (не в PATH; в Git Bash
  `B="/c/Program Files/Blender Foundation/Blender 5.2/blender.exe"`). Cycles на HIP (AMD RX 9060 XT, 16 ГБ):
  фон 1080 × 1920 × 160 сэмплов ≈ 35–45 с, предмет 512² ≈ 5 с, 9 жителей ≈ 45 с. Всегда `--python-exit-code 1`;
  рендеры кодера — только вне репозитория. Кодер для Blender — Opus, effort high/xhigh (Workflow
  `agent({agentType:'coder', model:'opus', effort:'xhigh'})`), не Sonnet из `coder.md`. Приёмка арта —
  `python tools/art_check.py` (regress/diff дампом сцены, bg — композиты UI на фон места с контрастом и
  пересветом, bbox, palette); листы ворот A1b собирал скрипт сессии (композиты с подменой аватаров жителей,
  честный 1:1) — его логика в `tools/art_check.py bg` и `tools/sheets.py`. MCP for Blender подключён
  (`claude mcp add blender -- uvx blender-mcp`): инструменты появятся в новой сессии, в Blender — N-панель →
  BlenderMCP → Connect; генераторы окно Blender не используют. Зонд устройства и импорт без побочных эффектов — команды в `TOWN-A1a.md`.
  Пользовательские аддоны (Extra Mesh Objects, Bool Tool, VRM, ARKit, Wiggle 2, Rokoko, MMD Tools…)
  генераторам не нужны: `reset_scene` грузит заводские настройки, аддоны там выключены — не завязываться.
- Эмулятор: AVD `finni`, запуск
  `"$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd finni -no-snapshot-save -no-boot-anim -no-audio &`;
  урезанный для замера плавности — плюс `-cores 2 -memory 3072 -gpu swiftshader_indirect`.
  Портрет: `tools/adbui.sh shell cmd window user-rotation lock 0` (одного `user_rotation 0`
  мало — эмулятор оставался в ROTATION_90). 360 dp — `tools/adbui.sh wm360`, сброс — `wmreset`.
