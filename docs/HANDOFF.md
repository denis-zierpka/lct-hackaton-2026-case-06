## Окружение (Windows 10, эта машина)

- JDK 17 Adoptium (`JAVA_HOME` уже задан), Android SDK — `%LOCALAPPDATA%\Android\Sdk`
  (platform 36, build-tools 36.0.0, emulator, образ android-36.1 google_apis x86_64),
  `finny-pet/local.properties` с `sdk.dir=C\:/Users/Singularity/AppData/Local/Android/Sdk`.
- Gradle: из `finny-pet/` — `./gradlew` в Git Bash (с `JAVA_HOME` в кавычках) или `.\gradlew.bat`
  в PowerShell. Вывод PowerShell с `*>` переносит длинные строки — для grep по ошибкам брать Git Bash.
- Эмулятор: AVD `finni` (WHPX), запуск
  `"$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd finni -no-snapshot-save -no-boot-anim -no-audio &`.
- Телефон команды: Samsung Galaxy S23 (SM-S911B), Android 14, adb serial `RZCX923ZP4L`, 360 dp.
  Есть «Защищённая папка» → `pm`/`am`/`install` с `--user 0`. **Тесты — без звука**: `tools/adbui.sh mute`
  перед прогоном, `unmute 11` после.
- Управление экраном: [`tools/adbui.sh`](../tools/adbui.sh) (`ANDROID_SERIAL=emulator-5554` или
  `RZCX923ZP4L`): `ui`, `tap "Текст"`, `shot`, `launch`, `wm360`, `font 1.3`.
- Роли контура (`test-author`, `coder`, `reviewer`) в этой машине не зарегистрированы как типы
  агентов (сессия стартовала до их появления) — их играют общие подагенты с текстом роли из
  `.claude/agents/*.md` в промпте; хук guard их не видит, поэтому целостность оракула проверяется
  приёмкой (`git diff <ORACLE_SHA> -- app/src/test/` → пусто). В новой сессии проверить:
  если типы появились — использовать их.
- Git worktree для параллельной работы: `git worktree add -b <ветка> .claude/worktrees/<имя> HEAD`
  + скопировать `finny-pet/local.properties`. Старые `.claude/worktrees/agent-*` можно удалить
  (`git worktree prune` после удаления папки; длинные пути — через `rm -rf` в Git Bash).
