**Уроки сессии 5** (кандидаты в WORKFLOW):
- Зелёная машинная приёмка UI-задачи ничего не говорит о UI: живая проверка нашла 14 дефектов после
  кодеров 1–2 и ещё 8 после правки (регрессии), ревьювер — 2, которые пропустила живая. UI без живого
  замера и потоков из ACCEPTANCE не принимать.
- Переупорядочил вызовы в VM — проверь, что читает навигация: `navigate` до `commit` видел старое
  `asleep`, «Проснуться» после перезапуска не выводил из ночи (R1). Порядок: commit → переход → строки.
- Одна подпись — одна формула на всех экранах («Не разложено» считалось по-разному в листе кошелька).
- Доки, которые читатели готовят параллельно с кодером, описывают промежуточный код: после финального
  коммита кода — вторая сверка (нашла 81 правку из 391).
- Замер до оптимизации (S1f): план «IO + LRU + async save» не решал измеримой проблемы — отложен с
  условием включения и порогами. Эмулятор на swiftshader: p50 ≈ 32 мс в покое, доля janky там не порог.
- Кодер на длинной правке упирается в лимит ходов — продолжать через SendMessage.
- Критики спек арта (41 находка) поймали то, что я не видел: Blender выходит с кодом 0 при исключении
  (нужен `--python-exit-code 1`), печать «cycles device» — не доказательство GPU (зонд по состоянию +
  замер на тяжёлом кадре: smoke 512² упирается в запуск Blender), `git diff` не видит новых файлов
  (`git status -uall`), `sheets.py` растягивал квадраты, фон места почти весь закрыт UI (≈ 200 dp сверху,
  карточки с 31 %) — композицию проверять композитами по маске со снимков.

## Окружение (Windows 10, эта машина)

- JDK 17 Adoptium (`JAVA_HOME` задан), Android SDK — `%LOCALAPPDATA%\Android\Sdk`
  (platform 36, build-tools 36.0.0, emulator, образ android-36.1 google_apis x86_64),
  `finny-pet/local.properties` с `sdk.dir=C\:/Users/Singularity/AppData/Local/Android/Sdk`.
- Gradle: из `finny-pet/` — `./gradlew` в Git Bash или `.\gradlew.bat` в PowerShell. Из Python
  вызывать `gradlew.bat` по абсолютному пути: `bash` из Python попадает в WSL. Кодеров с Gradle —
  по одному.
- **Blender 5.2 LTS** — `C:/Program Files/Blender Foundation/Blender 5.2/blender.exe` (не в PATH; в Git Bash
  `B="/c/Program Files/Blender Foundation/Blender 5.2/blender.exe"`). Cycles на HIP (AMD RX 9060 XT, 16 ГБ):
  фон 1080 × 1920 × 160 сэмплов ≈ 46 с, предмет 512² ≈ 5 с. Всегда `--python-exit-code 1`; рендеры кодера —
  только вне репозитория. Зонд устройства и импорт без побочных эффектов — команды в `TOWN-A1a.md`.
  Пользовательские аддоны (Extra Mesh Objects, Bool Tool, VRM, ARKit, Wiggle 2, Rokoko, MMD Tools…)
  генераторам не нужны: `reset_scene` грузит заводские настройки, аддоны там выключены — не завязываться.
- Эмулятор: AVD `finni`, запуск
  `"$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd finni -no-snapshot-save -no-boot-anim -no-audio &`;
