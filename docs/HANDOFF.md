## Окружение (Windows 10, эта машина)

- JDK 17 Adoptium (`JAVA_HOME` задан), Android SDK — `%LOCALAPPDATA%\Android\Sdk`
  (platform 36, build-tools 36.0.0, emulator, образ android-36.1 google_apis x86_64),
  `finny-pet/local.properties` с `sdk.dir=C\:/Users/Singularity/AppData/Local/Android/Sdk`.
- Gradle: из `finny-pet/` — `./gradlew` в Git Bash или `.\gradlew.bat` в PowerShell. Из Python
  вызывать `gradlew.bat` по абсолютному пути: `bash` из Python попадает в WSL. Кодеров с Gradle —
  по одному.
- Эмулятор: AVD `finni`, запуск
  `"$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd finni -no-snapshot-save -no-boot-anim -no-audio &`;
  урезанный для замера плавности — плюс `-cores 2 -memory 3072 -gpu swiftshader_indirect`.
  Портрет: `tools/adbui.sh shell cmd window user-rotation lock 0` (одного `user_rotation 0`
  мало — эмулятор оставался в ROTATION_90). 360 dp — `tools/adbui.sh wm360`, сброс — `wmreset`.
  На эмуляторе системная локаль en_US: русский перенос (`Hyphens.Auto`) — только с явной
  `LocaleList("ru")` в стиле текста. Громкость медиа эмулятора — 5 (`mute` перед проверкой, `unmute 5` после).
- Телефон команды: Samsung Galaxy S23 (SM-S911B), Android 14, serial `RZCX923ZP4L`, 360 × 780 dp.
  **Засыпает через 10 минут, отключить нельзя** — прогоны на телефоне делать сразу, будить
  `input keyevent 224`. «Защищённая папка» → `pm`/`am` с `--user 0`. **Тесты — без звука**:
  `tools/adbui.sh mute` печатает громкость — запомнить и вернуть `unmute <N>` (в сессии 3 было 5, потом 7).
  На телефоне — debug-сборка `feat/town` времён среза 0 поверх 1.3.0 (данные профиля сохранены).
- Живая проверка: [`tools/adbui.sh`](../tools/adbui.sh) (`ui`, `tap "Текст"`, `tapxy`, `shot`, `launch`,
  `wm360`, `font 1.3`, `mute`/`unmute`); замер экрана — `tools/ui_measure.py` по uiautomator-дампу
  (теги через `testTagsAsResourceId`, узел `overflow` «Обрезано: N» — только debug); листы скриншотов —
  `python tools/sheets.py OUT.jpg "Заголовок" emu_X.png "Подпись" …`; плавность — `tools/perf.sh`
  (`reset`, `frames`, `max`); зонды мутантов — `tools/mutation_probe.py`.
- Роли контура `test-author`, `coder`, `reviewer` — типы агентов (Agent/Workflow с
  `subagent_type`/`agentType`), хук guard их видит. Whitelist — `.claude/task-scope.json`
  (сейчас `TOWN-S1d-coder3`), переписать перед спавном кодера. Правки `docs/` и других
  protect-путей коммитить ДО спавна или возобновления кодера. Кодер упирается в 72 хода
  на больших задачах — продолжать через SendMessage.
- Workflow-скрипты: `${…}` внутри шаблонных строк промпта — подстановка JS; в тексте для
  агента экранировать `\${…}`. Результат workflow с большим выводом — брать из `journal.jsonl`
  (строки `type: result`), а не из усечённого уведомления.
