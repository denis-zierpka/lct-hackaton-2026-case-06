## ACCEPTANCE
Задача выполнена ⇔ все команды дают заявленный код.
Блок копируется из docs/ACCEPTANCE_PRESETS.md, команды — из finny-pet/:
  1. ./gradlew testClassicDebugUnitTest            -> exit 0
  2. tests = <было> + <N>, skipped = 0 (подсчёт по XML)
  3. ./gradlew assembleClassicDebug assembleGameDebug -> exit 0
  4. ./gradlew lintClassicDebug lintGameDebug      -> 0 ошибок, предупреждений ≤ 9 / 10
  5. git diff --name-only BASE -- app/src/test/    -> пусто
  6. git diff --shortstat BASE                     -> не более <N> строк

## Перед спавном кодера оркестратор пишет `.claude/task-scope.json`

```json
{
  "base": "<sha>",
  "allow": ["finny-pet/app/src/main/java/ru/finny/pet/domain/Economy.kt"],
  "protect": ["finny-pet/app/src/test/", "finny-pet/app/build.gradle.kts", "finny-pet/gradle/", ".claude/", "docs/"]
}
```

Этот файл — то, что хуки читают как источник истины. Спека без него не имеет силы:
всё, что написано в спеке словами, кодер может проигнорировать, всё, что в
`task-scope.json` — не может.

## Как не написать плохую задачу

| Симптом в спеке | Что произойдёт |
| --- | --- |
| «сделай удобный API» | кодер придумает свой интерфейс, ревью развалится на вкусовщину |
| ACCEPTANCE без команд | приёмка станет самоотчётом, весь контур бессмыслен |
| `allow` шире, чем нужно | попутный рефакторинг, раздутый диff, невозможность ревью |
| Тесты не написаны заранее | кодер напишет тесты под свою реализацию, оракул исчезнет |
| Нет ANTI-SCOPE | «я заодно улучшил...» |
| Несколько несвязанных изменений в одной задаче | FAIL нельзя локализовать, откатывать придётся всё |
